# 기록 문서 수정 규칙

- 아래 기록 문서는 사용자가 해당 문서의 작성·갱신을 명시적으로 요청한 경우에만 작성하거나 수정한다. 일상적인 업무 수행 요청만으로 기록 갱신까지 요청받았다고 해석하지 않는다.
- `3_PROGRESS.md`: 사용자가 요청하면 주요 변경과 이유를 기록한다.
- `5_HANDOFF.md`: 사용자가 인수인계 작성·갱신을 요청하면 현재 상태, 결정 이유, 남은 일과 주의점을 정리한다.
- `4_KNOWLEDGE_LESSONS.md`: 사용자가 요청하면 새로 확인한 사실과 교훈을 기록한다.
- `6_NOTE.md`: 사용자가 메모를 요청한 경우에만 작성하거나 수정한다.
- `7_VALIDATION.md`: 사용자가 요청하면 실제 수행한 검증 결과와 미검증 범위를 기록한다.
- 작업 완료, 세션 전환, 새로운 사실 발견, 검증 수행 자체는 위 문서를 자동 갱신할 권한이 아니다. 내용이 오래됐음을 발견해도 요청 없이 덮어쓰지 않는다.
- 이 규칙은 기록 문서의 작성·수정에 관한 것이다. 사용자 요청을 수행하는 데 필요한 작업과 검증, 채팅에서의 결과 설명은 계속 수행한다. 기록 내용을 다른 파일로 우회해 자동 저장하지 않는다.
